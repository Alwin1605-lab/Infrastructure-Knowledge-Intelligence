# Architecture Comparison (Ablation Analysis)\n\nThis document explains the incremental contribution of each architectural component based on the Pilot Experiment.\n\n## 1. LLM -> Vector Retrieval (RAG-only)\nAdding Vector Retrieval grounded the LLM, reducing hallucinations. Answer point coverage increased, but latency also increased slightly due to the ChromaDB query.\n\n## 2. Vector Retrieval -> Knowledge Graph (RAG+KG)\nAdding the Neo4j Knowledge Graph allowed structured entity retrieval, theoretically improving multi-hop queries. In this 5-question pilot, entity coverage increased, but overall answer quality remained similar.\n\n## 3. RAG+KG -> Hybrid Retrieval (Hybrid RAG)\nThe existing Phase 5 Hybrid RAG pipeline successfully executed, providing structured confidence and citations, though latency increased due to reranking.\n\n## 4. Hybrid Retrieval -> Agentic Reasoning (Hybrid RAG + Agentic AI)\nThe Agentic Orchestrator correctly delegated tasks across 5 agents. However, it significantly increased overall latency. For these 5 simple pilot questions, the agentic reasoning did not demonstrate a measurable improvement in answer point coverage over standard Hybrid RAG.\n\n
